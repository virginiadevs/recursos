# 🔍 Buscador de Recursos

Este repositorio reúne una colección de recursos digitales, útiles para el desarrollo web y el aprendizaje de nuevas tecnologías. Un espacio donde recopilo contenido de interés que puede servir como apoyo y referencia.

## ✨ Características

- 🔗 Enlaces a recursos, tutoriales y materiales de interés.
- 🛠️ Herramientas intuitivas y fáciles de utilizar.
- 🔎 Campo de búsqueda y filtros por categorías.
- 📚 Recursos para el aprendizaje teórico, práctico y mediante gamificación.

## 💻 Tecnologías utilizadas

- HTML5
- CSS3
- Javascript
- Fontawesome
